# Atelier Thorne — Bespoke Tailors

A multi-page website for **Atelier Thorne**, a fictional bespoke tailoring house in Bangkok. It's built as a single HTML file with vanilla HTML, CSS and JavaScript.

**Live site:** https://sudarsun-24.github.io/Tailor_trial/

## Pages

- **Home**: a hero with a tailor's work ticket, services, the cloth library, recent commissions, client quotes and a booking prompt
- **The atelier**: the house's story, milestones, the team and how they work
- **Services**: bespoke suiting, made to measure, formal and occasion wear, and alterations, with the four-step process and prices
- **Cloth**: six featured cloths with mills, prices and a guide to choosing
- **Work**: a gallery of 15 commissions, filterable by suits, formal, ladies' and outerwear, with a full-screen viewer
- **Contact**: address, hours, a map and a consultation request form

## Features

- Works on phones, tablets and desktops, with a full-screen menu and a booking bar on small screens
- Each page has its own link (for example `#services`), and the back button works
- Fade-in and "stitching" animations on scroll, switched off for visitors who prefer reduced motion
- Form checks required fields and email format before showing a confirmation
- Gallery viewer supports arrow keys and Escape
- Link previews (Open Graph) for sharing on social and messaging apps

## Built with

- HTML, CSS and JavaScript in one file (`index.html`), with no build step
- Google Fonts: Bodoni Moda, Hanken Grotesk and IBM Plex Mono
- Photography from [Unsplash](https://unsplash.com), used under the Unsplash License and stored in `images/` as WebP (sources listed in [`images/CREDITS.md`](images/CREDITS.md))
- Hosted on GitHub Pages

## Run locally

Clone the repo and open `index.html` in a browser.
