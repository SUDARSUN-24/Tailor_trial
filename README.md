# Atelier Thorne — Fine Tailors

A multi-page website for **Atelier Thorne**, a fictional bespoke tailoring house. It's built as a single HTML file with vanilla HTML, CSS and JavaScript.

**Live site:** https://sudarsun-24.github.io/Tailor_trial/

## Pages

- **Home**: hero section, featured work and client testimonials
- **About**: the atelier's story, a timeline, the team and its principles
- **Services**: bespoke suiting, made to measure, formal and occasion wear, alteration and restoration, plus how a bespoke garment is made step by step
- **Materials**: the finest fabrics, the most sought-after choices and a guide to choosing
- **Gallery**: a showcase of finished pieces
- **Contact**: an appointment enquiry form and studio details

Navigation switches between pages in place, with no page reloads.

## Built with

- HTML, CSS and JavaScript in one file (`index.html`), with no build step
- Google Fonts: Playfair Display, DM Serif Display and DM Sans
- Hosted on GitHub Pages

## Run locally

Clone the repo and open `index.html` in a browser.

## Notes

This is a design concept. The business, contact details and testimonials are placeholders, and the enquiry form doesn't send messages anywhere.
